# Website Giới thiệu Tiệm Trà Sữa Đại Nam
Bài tập lớn A3 - Học phần FIT4014: Thiết kế web và triển khai hệ thống phần mềm.

## Cấu trúc thư mục
- `index.html`: Trang chủ chứa các phần Giới thiệu, Menu đồ uống, Về chúng tôi và Liên hệ.
- `css/style.css`: Tệp định dạng giao diện tông nâu trà sữa và cấu hình Responsive cho điện thoại.

## Hướng dẫn chạy
1. Mở trực tiếp tệp `index.html` bằng trình duyệt web bất kỳ (Chrome, Edge...).
2. Hoặc truy cập đường dẫn GitHub Pages đã triển khai.
